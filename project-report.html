1. Project Overview

Ghousia Dairy Food is a fully functional food ordering and product catalog web application. It was designed and developed as a modern, mobile-first web application that allows customers to browse products, search items, view product details and place orders directly via WhatsApp.

The application serves as a digital storefront for a real physical shop in Multan — replacing the need for a traditional app or third-party delivery platform, while keeping ordering simple through WhatsApp which the business already uses.

🎯 Primary Purpose

Digital product catalog and WhatsApp ordering system for a local food business

📱 Mobile-First

Fully responsive design optimised for Android and iOS mobile browsers

⚡ Performance

SSR-enabled TanStack Start for fast page loads and SEO-friendly rendering

🔒 No Backend Needed

Serverless-friendly — products are static data, orders go via WhatsApp

5. Application Architecture

Rendering Strategy

The app uses Server-Side Rendering (SSR) via TanStack Start + Nitro. Pages are rendered on the server, sent as HTML to the browser, then React hydrates them for interactivity.

LayerTechnologyRole
RoutingTanStack Router (file-based)Handles all URL navigation and code splitting
SSR ServerNitro + src/server.tsRenders pages server-side, serves HTML
UI LayerReact 19 + Tailwind CSSAll visual components and styling
StateZustand (cart) + React useStateClient-side state management
DataStatic TypeScript filesAll products, brand info stored as TS constants
OrdersWhatsApp wa.me APIOrder messages sent via WhatsApp links
BuildVite + @lovable.dev/vite-tanstack-configBundles and optimises the app
DeployNetlifyHosting with Nitro cloudflare adapter

13. Search System

How Search Works

  1. User types in the search bar (header on desktop, below header on mobile)
  2. Suggestions dropdown appears instantly with up to 6 matching products
  3. Each suggestion shows a product-specific emoji, product name, category and price
  4. Partial word matching — typing "ice" shows "Ice Cream", "fri" shows fries
  5. Clicking a suggestion navigates directly to the product detail page
  6. "See all results" link at bottom searches the full menu
  7. Press Escape or click outside to close suggestions

14. Cart System

Cart Features

  • Add to cart from product tiles and product detail pages
  • Quantity increment / decrement controls
  • Remove individual items
  • Cart count badge on cart icon (header + bottom nav)
  • Persisted to localStorage via Zustand persist middleware
  • Cart survives page refresh and browser close/reopen
  • Estimated subtotal calculation with per-item price × quantity
  • One-click WhatsApp checkout with full formatted order message
  • "Clear cart" option after ordering

Cart State (Zustand Store)

type CartItem = { id: string; name: string; qty: number }

Cart actions:
  add(product)         → adds 1 qty or increments existing
  remove(id)           → removes item completely
  setQty(id, qty)      → sets exact quantity (0 = removes)
  clear()              → empties cart
  count()              → total item count

Netlify Deployment

The project is configured for Netlify deployment via netlify.toml. The Nitro server uses Cloudflare adapter for edge deployment.

Steps to deploy:

  1. Push code to GitHub: git push
  2. Connect GitHub repo to Netlify
  3. Netlify auto-detects build settings from netlify.toml
  4. Click Deploy — live URL generated automatically
